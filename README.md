# Whitepaper Reading Club · Reading Hub

A public home for the papers we read, the notes we take, and the conversations we share.

Anyone can browse and share these pages. To suggest a paper, ask a question, or contribute, sign in to GitHub.

## Explore

- [Reading library](papers/README.md) — find papers and their related notes and transcripts.
- [Session archive](sessions/README.md) — browse reading sessions by date.
- [Suggest a paper or ask a question](https://github.com/Whitepaper-Reading-Club/whitepaper-reading-hub/issues/new) — join the conversation.
- [Contribute](CONTRIBUTING.md) — add a paper, notes, or a transcript.

## Reading library

No papers have been added yet. Add the first paper using the [paper template](templates/paper.md), then link it in the reading library.

## Add a reading session

Create a folder such as `sessions/YYYY-MM-DD-paper-slug/` and add:

- `README.md`: the [session overview](templates/session.md), with links to the paper, notes, and transcript.
- `notes.md`: key ideas, questions, and takeaways using the [notes template](templates/notes.md).
- `transcript.md`: the discussion text using the [transcript template](templates/transcript.md).

Add the session to the [session archive](sessions/README.md) and link it from its paper page. Each file has its own URL that you can share with readers.

## Publishing

This repository is public. Publish only material intended for public sharing, and get speakers' permission before posting their words. Link to original papers; upload copies only when redistribution is permitted. Keep source claims, participant opinions, and editorial summaries clearly distinguished.
